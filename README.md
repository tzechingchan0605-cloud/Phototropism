# VL3 · 幼芽的向光性

以 VL1（未知消化液）與 VL2（西芹水分運輸）的介面及探究流程為參考，建立繁體中文的向光性虛擬實驗室。HTML、CSS、JavaScript 前端搭配 Python 標準函式庫伺服器及 SQLite 共用紀錄資料庫；應用程式不需要安裝第三方套件。

## 啟動與教師密碼

在儲存庫目錄執行：

```sh
python3 server.py
```

預設 port 8000，可用 `--port` 或 `PORT` 調整。亦可執行 `npm start`。瀏覽器必須開啟這個伺服器提供的網站；一般檔案伺服器、直接開 HTML 或純靜態網站不會提供共用紀錄 API。

第一次啟動會在 `.data/teacher-password` 產生隨機教師密碼（只有檔案擁有者能讀取）。你可在自己的終端以互動方式設定密碼：

```sh
python3 server.py --set-teacher-password
```

輸入至少 12 字元的密碼及確認；不要把密碼放在程式碼、Git 或聊天。伺服器也支援從部署平台的安全設定注入 `VL3_TEACHER_PASSWORD`；此值優先於本機密碼檔。修改後重啟伺服器以清除舊登入階段。

## 不同瀏覽器、同一份教師 Excel

所有學生必須使用**同一個已部署的 VL3 網站**。學生姓名、班別、電郵、作答、裝置圖及操作事件會自動傳至 `/api/records`，集中儲存於同一個 SQLite 資料庫。頁面顯示同步狀態；斷線期間保留本機待傳紀錄，連線恢復後重試。關閉前請確認「作答已同步」；尚未同步的資料仍依賴原瀏覽器保留。

教師登入後，`/api/records` 讀取所有裝置已同步的紀錄，匯出前再次讀取最新資料，因此同一個 Excel 包含全部學生。下載的 XLSX 是當時的快照；新作答加入後需重新下載，新紀錄不會自行寫入之前下載的 Excel。舊 Excel 內人工分數仍只存在該檔案，重新匯出不會讀入舊檔的人工分數。

舊版 localStorage 紀錄在原瀏覽器再次開啟新網站時自動遷移；若更換網站來源，需在原網站下載 JSON，再由教師匯入。新網站不能直接讀取另一個來源的 localStorage。JSON 匯入是舊紀錄轉移／備份用途，新作答不需要手動匯入。

每份學生紀錄有不可猜測的寫入憑證，教師读取需要 HttpOnly session cookie。教師示範不寫入學生資料。紀錄寫入會保留第一次實驗前的原始假說，以及第一次觀察；舊版本重試不覆蓋較新的版本。

## 部署

部署至可長期執行 Python 程式、提供 HTTPS 並保留持久磁碟的主機。啟動指令是 `python3 server.py`；網站頁面與 `/api/*` 必須轉送到同一個伺服器。GitHub Pages 等純靜態服務不能單獨執行此後端。

- `VL3_DATA_DIR`：共用資料庫、教師密碼檔所在的持久目錄，預設 `.data/`。不要放在公開靜態目錄；本伺服器只公開四個網站檔案，不公開資料目錄。
- `VL3_TEACHER_PASSWORD`：可選的部署密碼，從主機安全設定注入，不要填入 Git。
- `VL3_SECURE_COOKIES=1`：在正式 HTTPS 部署啟用 Secure cookie。本機 HTTP 測試不設定此項。
- `PORT`：主機指定的 HTTP port，預設 8000。

請備份整個資料目錄，含 SQLite 的 WAL 檔，或停止伺服器後備份。此實作適合单一伺服器及共享持久磁碟；多個各有獨立磁碟的實例不會共享資料。發布程式碼本身不代表已部署網站；請確認正式網址的 `/api/health` 回應 `sharedRecords: true`，並以兩個不同瀏覽器實測學生上傳與教師匯出。

## 學生探究

1. **了解情境**：觀察幼芽向單側光源彎曲，記錄初步觀察。
2. **設計探究**：假說兩個選單不預選答案；部位、反應及理由必填。完成變量、前提、對照組及裝置設計（繪圖、相片或文字）。首次進入實驗前固定保存完整原始假說與理由，日後修改不會覆蓋。
3. **進行探究**：四組相同單側光照：A 不遮光；B 頂端不透光罩；C 頂端透明罩；D 頂端以下遮光、頂端外露。學生自行判斷及記錄結果；第一次觀察及修訂事件均保存。
4. **分析與結論**：提交結論後鎖定答案，顯示感光、生長部位及生長素機制。完成反思後可列印／儲存 PDF，亦可下載 JSON 備份。

模型以禾本科幼芽的胚芽鞘呈現典型反應：A、C、D 向光彎曲，B 沒有明顯彎曲；罩子及套筒假定不限制生長。動畫為加速示意，不是真實時間或量度，也不模擬個體差異。機制區分頂端感光及頂端以下細胞伸長：背光側生長素較多，促進幼芽細胞伸長而彎向光源。遮光實驗沒有直接量度生長素；機制來自其他研究，不能由本模型直接證明，也不能直接套用至根。

## 教師報告

Excel 有七頁：學生探究答案、四組觀察紀錄、教師評分、評分準則、操作事件紀錄、原始與遞交快照、裝置設計圖。保留類別底色、正誤字色、裝置圖、九項可填整數教師分數及公式。六項科學過程技能（SPS）各 4 分，共 24；知識 8 分；整體 32 分。人工格空白是「待評」，0 是明確零分；反思完成及所有人工評分填妥後才顯示整體分數。

評分準則為活動用草案；原始假說以可測試性與理由評分，不因預測與模型不同便判錯。

## 驗證

測試依賴只供開發，應用程式本身不需要安裝：

```sh
npm ci
python3 -m pip install -r requirements-test.txt
npm test
```

測試預設使用 `/usr/bin/chromium`，其他系統可設 `CHROMIUM_PATH` 為 Chrome／Chromium 執行檔路徑。測試自動啟動隔離的伺服器與暫存資料庫，不改動 `.data`。

瀏覽器測試涵蓋完整學生流程、必填、原始快照、第一次觀察、提交鎖定、反思、PDF 列印觸發及實際 PDF 產生、XLSX 下載、獨立瀏覽器共用資料、教師權限、斷線重試、JSON 匯入及 390px 手機版。Python 檢查實際匯出的 XLSX 結構、圖片、樣式、人工分數與公式；以受控 evaluator 測試公式，不宣稱已在桌面 Excel 執行。後端測試驗證持久紀錄、寫入憑證、過時重試、原始快照、防止跨來源寫入、登出及伺服器重啟後紀錄保留。

測試輸出虚構學生紀錄到 `/tmp`，不加入正式資料庫。
