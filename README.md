# VL3 · 幼芽為甚麼朝光生長？

參考 VL1 與 VL2 的繁體中文探究流程，保留假說、公平測試、裝置繪圖／相片、四組實驗、結論、反思、PDF 及教師 Excel 評分。HTML、CSS、JavaScript 前端可部署到 GitHub Pages；共用紀錄由 **VL3 專用 Google Apps Script** 寫入私人 Google Sheet。

## 雲端收集設定

完整可貼入 Apps Script 的程式：[cloud/Code.gs](cloud/Code.gs)。中文及英文設定與正式驗證步驟：[cloud/SETUP.md](cloud/SETUP.md)。`cloud-config.js` 已接入使用者提供的 VL3 `/exec` 網址，透過嵌入頁及 `google.script.run` 傳送紀錄。只有收到真正的探究 ID／版本儲存確認才顯示「已同步」。

教師用 `tzechingchan0605@gmail.com` 和私人 Script Properties 設定的獨立密碼讀取全班資料。學生自行輸入電郵；手機或瀏覽器登入的 Google 帳戶不決定紀錄歸屬。學生電郵未經 Google 身分驗證。前端密碼只留於記憶體；教師示範不寫入學生紀錄。

每次探究獨立保存，重試不新增副本，較舊版本不覆蓋新答案。完整本機備份包含答案、圖片、原始／最後快照、反思、操作事件及用時，斷線後可補傳。只有核對探究 ID 和版本的真正儲存回應才顯示「已同步」。原本機儲存鍵及舊紀錄保留。

教師列表及 Excel 逐頁讀取全部雲端紀錄；匯出前重新讀取。任何讀取失敗都停止全班匯出。下載的 XLSX 是當時快照；新作答需重新下載，人工評分只留於該 Excel。

## 中文／英文語言切換

每次開啟或重新整理頁面都預設繁體中文，不沿用上次的語言。登入視窗、學生頁面及教師視窗右上角均有「語言：中文 / English」按鈕，教師示範亦可使用。按一下即可直接切換中文／英文，毋須輸入語言代碼。

英文一般指示使用簡單英文，例如 **experiment setup**、**the factor changed on purpose**。保留 Independent variable、Dependent variable、Controlled variables，並附簡單英文解釋。生物專有詞保持科學準確；學習名稱與機制仍在遞交探究後才開放。

使用者批准的中文括號支援**只有以下六項**；大小寫、單複數及 elongation 的動詞形式按句子調整。其餘英文詞彙不加中文，`hormone` 已按使用者更新排除。要新增支援詞彙，須先列候選並取得使用者選擇。

| 英文詞彙     | 已批准的中文支援 |
| ------------ | ---------------- |
| coleoptile   | 胚芽鞘           |
| phototropism | 向光性           |
| auxin        | 生長素           |
| agar         | 瓊脂             |
| elongation   | 延長             |
| opaque       | 不透光           |

完整翻譯包括登入、探究、教師示範、動態訊息、所有文字／數字輸入框的 placeholder、SVG 圖示文字、替代文字及 PDF 的題目和參考說明。學生姓名、理由、設計、反思等原文不翻譯；舊紀錄亦保留原文。切換只改顯示文字及提示，不重建實驗控制項、不改答案 value／選項順序、不清空畫布、不重啟動畫，也不更改探究 ID、快照、事件、計時、提交鎖定及同步備份。

**教師 Excel 永遠保持繁體中文**。英文介面不翻譯學生答案，亦不更改評分、公式或圖片。PDF 題目、說明及圖示跟隨當前介面語言，學生文字保留原文。翻譯來源及批准詞彙在 `i18n-strings.js`；顯示層、來源文字及語言切換在 `i18n.js`。Excel 從來源選項文字取值，避免把英文化顯示標籤寫入作答或評分。

## 本機開發

在儲存庫執行 `python3 server.py` 或 `npm start`，預設 port 8000。也可用靜態 HTTP 伺服器；不需要前端建置或第三方執行期套件。共用紀錄需要上述 Apps Script 設定，Python 伺服器的舊 `/api/health` 成功不代表新的 Google 同步已接通。

舊 Python／SQLite API 保留供既有紀錄備份及相容驗證，新前端使用 Apps Script。保留忽略的 `.data/`，遷移方法見設定文件。不要把教師密碼或學生資料加入 Git。

## 學生探究與教學模型

活動名稱：《幼芽為甚麼朝光生長？》。先介紹燕麥胚芽鞘是保護內部嫩葉的鞘狀構造；主探究用 A–D 左側光照定性比較，延伸用 E–H 黑暗中的空白／處理瓊脂，加入虛擬量角器和棒形圖。名稱「向光性／正向光性」及生長素機制在主、延伸遞交鎖定後才顯示；反思提交後開放學生 PDF。

原始主探究假說、延伸預測、首次與最後觀察／角度／圖表及修訂事件獨立保存。C 切頂組在本教學模型中不伸長；這不代表所有切頂植物都完全停止生長。動畫、24小時及角度清楚標示為教學模擬。完整假設、30–40分鐘試教目標、紙本對照材料及研究者待確認項目：[docs/TEACHING_NOTES.md](docs/TEACHING_NOTES.md)。

## PDF 與教師 Excel

學生只提供 PDF 匯出：卡片內包含兩次原始預測、設計、定性觀察、首次／最後量度、棒形圖、結論、共用 SVG 學習圖及實際反思。客觀題提供✓／✕及參考答案，開放題只提供參考說明；學生報告不顯示分數。預設列印檔名 `VL3_幼芽為甚麼朝光生長_[班別及學號]_[姓名]`。

教師 Excel 八頁：學生探究答案、四組觀察紀錄、延伸量度與棒形圖、教師評分、評分準則、操作事件紀錄、原始與遞交快照、裝置設計圖（含學生棒形圖圖片）。六項 SPS 各4分共24；四項知識各2分共8；整體32。十項人工評分、空白待評／零分區分、分類底色及正誤字色保留，不以完成率、用時或點擊直接評能力。評分為待跨VL校準初稿。

新版 `experimentVersion: 4` 保留瓊脂延伸，C 組設為不伸長。版本 3 的 C 組仍以較少伸長評閱；更舊的透明罩組及切頂四組紀錄亦按原版本顯示、評分及匯出，不修改原學生答案。已移除「指定比較」下拉題及開始實驗門檻，舊答案保留於舊版欄位。

「此探究的假設是什麼？」下方以灰色小字說明假設的定義；主探究材料清單不列培養容器。各階段未完成作答或未確認紀錄時，以 VL1／VL2 同類的浮動訊息提醒並捲到相關位置；使用者可繼續完成原本作答。

## 驗證

```sh
npm ci
python3 -m pip install -r requirements-test.txt
npm test
```

開發測試使用 `/usr/bin/chromium`，可由 `CHROMIUM_PATH` 指定替代執行檔；實際 PDF 內容檢查需 `pdftotext`（Debian／Ubuntu 套件 `poppler-utils`）。測試啟動隔離的模擬 Google 收集端及暫存資料庫，虛構紀錄與匯出檔留於 `/tmp`，不改動正式 `.data`。

涵蓋完整學生流程、原始與最後快照、切頂及長套筒、伸長動畫、瓊脂延伸、量角器、棒形圖、延後揭示、反思、實際 PDF 和 XLSX、獨立學生與教師瀏覽器、手機尺寸、同電郵多次探究、離線重整補傳、錯誤儲存確認、權限、分頁及不完整匯出阻擋。另檢查 Apps Script 初始化、JSON 分段、圖片、公式安全、舊版本相容及教師示範排除。

`tests/language.cjs` 由 `tests/cloud.cjs` 使用隔離的 Google 服務模擬及本機嵌入連線執行。它檢查直接切換中文／英文而不彈出輸入視窗、系統文字與全部輸入提示、原文／畫布／控制項／鎖定／動畫保存、PDF、兩種語言匯出的實際 XLSX 位元組一致（含評分、公式及圖片）、教師示範排除、手機、離線待傳／補傳及重整回到中文。測試阻擋所有非本機網路目的地；不使用正式 `/exec`，不把測試資料上傳正式收集端。

Python 檢查實際 Excel 的八頁、裝置與棒形圖圖片、樣式、十項人工評分欄、空白與零分及評分公式；公式以受控 evaluator 驗證，並未在桌面 Excel 執行。舊 SQLite API 另作相容測試。

**雲端流程測試模擬 Google 服務。** 最新 `/exec` 網址已接入，正式網址的匿名健康檢查回覆 `VL3集中紀錄`、版本 3，嵌入頁亦可匿名讀取並包含 VL3 連線協定及 `google.script.run`。開發環境的 Chromium 因憑證信任錯誤未能完成嵌入 RPC；尚未驗證正式儲存、教師雲端匯出或實體手機。需依設定文件在正式網站檢查儲存確認，再以獨立教師密碼核對全部雲端紀錄及 Excel。
