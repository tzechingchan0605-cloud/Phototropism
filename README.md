## 中文／英文語言切換

每次開啟或重新整理頁面都預設繁體中文，不沿用上次的語言。登入視窗、學生頁面及教師視窗右上角均有「語言：中文 / English」按鈕，教師示範亦可使用。按一下即可直接切換中文／英文，毋須輸入語言代碼。

英文一般指示使用簡單英文，例如 **experiment setup**、**the factor changed on purpose**。保留 Independent variable、Dependent variable、Controlled variables，並附簡單英文解釋。生物專有詞保持科學準確；學習名稱與機制仍在遞交探究後才開放。

## 學生探究與教學模型

活動名稱：《幼芽為甚麼向光生長？》。其餘生物學描述使用「胚芽鞘」，先介紹燕麥胚芽鞘是保護內部嫩葉的鞘狀構造。新版依次進行三項探究：

1. **主探究 A／B／C**：三組頂端均完整，只改變遮光處理（不遮光／頂端遮光／下部遮光），只記錄彎曲方向，推論感光部位。主探究材料為三株胚芽鞘，不列剪刀。
2. **延伸一 A／D**：只記錄是否有延長，分析頂端的存在是否影響生長，再提出頂端可能產生暫稱「物質 X」的待測想法；不另問彎曲方向、公平比較或推論限制。
3. **延伸二 E／F／G／H**：沿用黑暗中的空白／處理瓊脂、虛擬量角器，探討生長促進作用能否傳遞及其位置如何影響彎曲。E–F 只改變瓊脂是否曾接觸頂端；F–G–H 只改變處理瓊脂的位置。材料為四株切頂胚芽鞘、四個培養容器、一份空白瓊脂、三份處理瓊脂及計時工具。

物質 X 是暫稱，切頂或瓊脂比較本身都沒有鑑定其身分。必須完成三項探究的記錄與分析並確認遞交，才開放「向光性／正向光性」及其他研究支持的生長素機制。反思解釋情境圖中胚芽鞘為何向右彎曲；提交反思後才開放學生 PDF。

原始主探究假說、延伸一預測、延伸二預測連同理由分開保存；主探究及延伸一的首次／最後定性觀察、延伸二首次／最後角度與方向及修訂事件亦各自保留。D 切頂組在本教學模型中不延長；這不代表所有切頂植物都完全停止生長。動畫、24小時及角度清楚標示為教學模擬。完整假設、三項探究的試教時間待確認項目及紙本對照材料：[docs/TEACHING_NOTES.md](docs/TEACHING_NOTES.md)。

## PDF 與教師 Excel

學生只提供 PDF 匯出：卡片內包含三項原始預測與理由、設計、主探究及延伸一定性觀察、首次／最後量度、結論、共用 SVG 學習圖及實際反思。客觀題提供✓／✕及參考答案，開放題只提供參考說明；學生報告不顯示分數。預設列印檔名 `VL3_[班別及學號]_[姓名].pdf`。

教師 Excel 八頁：學生探究答案、定性觀察紀錄、延伸量度與棒形圖、教師評分、評分準則、操作事件紀錄、原始與遞交快照、裝置設計圖（繪圖／相片；舊版保留棒形圖圖片）。六項 SPS 各4分共24；四項知識各2分共8；整體32。新版11項人工評分（舊版10項）、空白待評／零分區分、分類底色及正誤字色保留，不以完成率、用時或點擊直接評能力。「定性觀察紀錄」以探究階段區分主探究 A／B／C 與延伸一 A／D；新增延伸一欄位亦包含原始預測及物質 X 的待測想法。評分為待跨VL校準初稿。

現行 `experimentVersion: 18` 將遮光主探究、頂端比較及瓊脂延伸分開；新增紙本材料不改學生紀錄 schema。版本 4 與更早的四組主探究、舊題目、變量文字、假說與快照仍按原版本顯示、評分及匯出，不把舊答案改作新版答案，也不補造延伸一紀錄。版本 3 的 C 組以較少延長評閱，版本 4 的 C 組以不延長評閱；更早的透明罩組及切頂四組紀錄亦保留原意義。已移除的「指定比較」下拉題答案仍留在舊版欄位。

「此探究的假設是什麼？」下方以灰色小字說明假設的定義；主探究材料清單不列培養容器或剪刀；延伸一沿用目前頁面，沒有恢復已刪材料清單。各階段未完成作答或未確認紀錄時，以 VL1／VL2 同類的浮動訊息提醒並捲到相關位置；使用者可繼續完成原本作答。
