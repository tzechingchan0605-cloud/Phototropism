# VL3 教學模型、研究程序及紙本對照

現行學生題目以 VL 頁面為準，題目版本為 18。紙本材料從同一 DOM、選項、模型及教師 Excel rubric 抽取，不另維護題目副本。VL1 參考為 Digestive-System 的 `6ce583b`／紙本 v3；僅參照介面、兩行作答及合併排版，沒有加入消化系統內容。

## Proposal 對照

已閱讀使用者提供的研究 proposal。4.1 指定兩組使用相同情境、靜態資料及問題；4.3.2 指定四週模組在正式授課前進行，紙本以靜態圖及預先製作資料表代替互動模擬。因此本材料保持同一植物情境、概念、題幹、提示、選項、實驗條件、資料、學習重點及反思。

每週活動材料與 Week 0／四週後的正式 10 題 SPSAI、4 題 CKT 前後測分開，不把實驗組專用後測意見題或訪談加入學生工作紙。本文及程式沒有把活動 rubric 當成已驗證的 SPSAI／CKT，也不宣稱研究預期效果已獲證實。

Proposal 未指定本模組分鐘數、分冊頁數或紙本回收方法。兩組須使用同一語言、相同可用時間及同樣資料揭示安排，由研究者訂定共同程序，並記錄程序偏差。

## 現行探究順序與模型

1. 窗邊胚芽鞘前後情境及初步觀察，接著完成主探究假說、理由、三類變量、前提、對照組及裝置設計。
2. 主探究顯示 A 不遮光、B 頂端遮光、C 頂端以下遮光。頂端全部保留，光源在左方，其他條件相同；只記錄彎曲方向。模型 A、C 向左彎曲，B 無明顯彎曲。
3. 延伸一比較完整 A 與切頂 D；先保存預測與理由，再記是否有延長，完成一題結論。模型 A 有延長，D 沒有；不另問方向、公平條件或證據限制。
4. 物質 X 過渡句後，延伸二比較黑暗中的 E 空白瓊脂中央、F 處理瓊脂中央、G 處理瓊脂左側、H 處理瓊脂右側。先保存預測與理由，再量度角度及判讀方向，完成現行三題分析（第3題為三個句內填空）。不恢復棒形圖、延長觀察題、公平比較題、額外對照或已刪推論題。
5. 固定三項探究答案後才揭示現行四項學習重點與兩幅機制圖；最後以原情境24小時後的右側光源圖完成學習反思。

底層舊紀錄 ID 保持不變：主探究 stored A/B/D 顯示 A/B/C，延伸一 stored A/C 顯示 A/D。不要直接改 stored IDs，否則會改變舊紀錄意義。舊版仍使用原題目、模型及答案；新材料只涵蓋現行版本。

主探究及頂端比較以定性判讀為主，不增加長度、濃度或速率數值。延伸二模型 E=0°、F=0°、G=35°向右、H=35°向左；E 不延長，F/G/H 延長。瓊脂寬度、放置位置及隨頂端傾斜的角度與 VL 相同。角度是頂端方向與鉛直參考線的夾角，不是整條曲線的平均方向。E/F 只接受0°，G/H接受33–37°（35°±2°）。角度、培養時間及動畫是固定教學參數，不是真實實驗常數。

主探究材料沿用 VL，包括三株燕麥胚芽鞘、三個單側光源、遮光帽、遮光套、直尺及計時工具。延伸一不恢復已刪材料清單；延伸二沿用四株切頂胚芽鞘、四個培養容器、一份空白瓊脂、三份處理瓊脂及計時工具。

## 派發、固定原始答案與頁面安排

- **A：情境與原始探究設計，兩語各3頁。** A1 是情境、初步觀察及研究問題；A2 是假說、理由、變量與修訂紀錄；A3 合併前提、對照組與裝置設計。先收存／拍照原始答案及設計，學生保留副本，才派 B。
- **B：實驗資料、分析與結論，兩語各4頁。** B1 合併主探究初始／結果圖與觀察表；B2 合併主分析、延伸一預測、圖像、觀察及結論；B3 是瓊脂過渡、預測／理由與條件；B4 是四組初始／結果圖、角度及方向紀錄與三題分析。每段預測固定後才顯示該段結果，可遮蓋同頁未到階段的圖；保留首次紀錄，修訂另外填。三項探究答案固定後才派 C。
- **C：學習重點與反思，兩語各2頁。** C1 合併現行四項重點與兩幅機制圖，C2 保留原情境結果圖及現行反思題。已刪的學生證據界限段落不加回；界限只供教師在 D 核對。
- **D：教師指引、答案與評分準則，繁中4頁、英文5頁。** 英文 rubric 文字較長，保留完整準則而分為兩頁。完整教師套裝為繁中13頁／英文14頁，不能整套直接派給學生。

每冊實際頁碼、套裝範圍、版本、檔名及下載連結由生成程式更新至 [materials/README.md](../materials/README.md)、根 README 及 manifest。

姓名、班別、學號只在 A1、C1，不在其他頁重複，亦不帶入真實個人資料。文字作答／修訂區各兩條線；角度數字留空，方向及原下拉選項為句內括號圈選，多選保持方格。35 mm 繪圖框放在兩行文字設計前。學生 A–C 不含對錯符號、參考答案或能力分數。

兩句提醒與 VL 共用：繪圖區為「不用精緻地繪畫所有特徵，簡單繪畫並標示清楚便可。」；前提題下為「假設是指未經證實而被視為正確的條件，用於確保實驗結果的有效性。」英文使用使用者指定版本，其餘英文沿用現有映射及六項批准中文支援（coleoptile、phototropism、auxin、agar、elongation、opaque）。

## 評分與證據界限

活動 rubric 是待跨 VL 校準的初稿：六項 SPS 各4，共24；新知識共8；總32。新版11項教師分數、舊版10項；空白是待評，0 是明確零分。合理可測試假說不能只因預測與模型不同扣分。紙本依相同準則由教師批改，不聲稱能自動讀取手寫文字。

變量分類與現行 PDF／Excel 共用判定：獨立及因變量各1，控制變量完整選對且不多選得2，漏選或多選0。主探究方向與延伸一延長觀察各1分。結論共7題，答對比例換算2分；瓊脂第3題三個填空各佔該題三分之一。量角器四組各0.5分。開放答案、裝置品質及反思仍由教師評閱，不以字詞命中自動判分。

切頂亦造成傷口及移除組織；瓊脂比較支持可轉移的生長促進作用，但沒有單獨鑑定物質 X，也沒有直接量度單側光照下的生長素分布。這些是教師理解模型的界限，沒有恢復已刪學生題目。

紙本閱讀靜態圖及使用實體量角器，VL 使用動畫與可調指針，兩者操作不是完全等同。不能把完成率、用時或點擊直接換成能力分數，也不能捏造紙本操作事件。研究者仍需核對跨組時間、原始答案副本與回收、資料揭示、量角器讀圖的可比性、rubric／評分者一致性、跨四週校準及正式前後測工具的適用性。

## 自動生成、隔離與實際驗證

`npm run materials:build` 使用隔離 Chromium 從共用來源自動產生真正的 A4 PDF，文字可選取，字形嵌入，圖示為向量。`npm test` 先重建來源有變的材料；未變則核對 checksum 而不重寫 PDF。manifest 記錄來源 digest、題目版本、選項 ID／順序、十份 PDF 的檔名／SHA-256、頁數、頁碼、作答線位置及排版檢查。

教師預覽及下載核對當前共用內容 digest，再核對 PDF 的 SHA-256。過期／損壞材料拒絕使用，可重新載入。入口檢查既有教師模式，不要求先完成示範或解鎖雲端學生列表；沒有新增 Apps Script。生成、預覽及下載不保存答案、繪圖、事件、計時或學生／雲端紀錄，不把資料排入同步佇列，不改教師 Excel。

測試包括：逐一比對現行文字題／選項，十份實際兩語 PDF 下載與 checksum，全頁文字、字型、A4分頁／溢出、實際向量兩行作答區、姓名欄位置、圈選／複選、繪圖先後、全套彩色／灰階渲染、教師入口與手機、過期／損壞攔截，以及完整學生紀錄、本機／雲端、示範畫布／欄位、計時／事件及實際 Excel 位元組下載前後相同。另在隔離副本更改共用題目，確認版本更新、十份材料重建及舊版本移除。

自動模擬不是正式 Google 部署或真實班級試教的替代品；仍需實體印表機試印（尤其量角器及灰階圖）、正式網站瀏覽器與手機下載、教師間評分及共同時間安排。正式學生 collector 不接收本次測試資料。
