# VL3 紙本比較組：自學程序及研究對照

學生 VL 保持題目版本 18、IBL 流程、動畫、原始預測、評分、雲端與舊紀錄。紙本教學版本獨立為 **WS2**，按使用者最新批准條件重設：比較組沒有課前講授、不操作 VL，只靠工作紙自學。學生課題名稱為「植物的感光與生長」。

## 教學順序與內容來源

**概念解說 → 已解說示例 → 有提示練習 → 獨立應用 → 核對修正**。A 開始即可閱讀，不再先收原始假說才提供概念；B 完成後才派 C。D 及完整教師套裝不能整套發予學生。

[paper-content.js](../paper-content.js) 是唯一紙本教學及等值題來源。它只讀抽取 VL DOM、題目／選項常數、SVG 模型、學習重點及反思，增加版本化自學解說、示例、派發程序、等值練習及獨立紙本評分。不抄寫另一套實驗模型，不讀學生答案或畫布。兩語共用同一結構與資料；現有英文詞彙規則及六項中文支援保留。

VL1 Digestive-System `6ce583b`／紙本 v3 只供下載介面及排版參考，不移入消化系統內容。已閱讀使用者 proposal；最新批准的比較組自學順序及 15–20 分鐘時限取代先前照搬 VL 的材料流程。維持共同情境、內容、技能及模型資料；合理題目可以相同或等值改寫，逐項理由見 [PAPER_QUESTION_MAPPING.md](PAPER_QUESTION_MAPPING.md)。正式 10 題 SPSAI／4 題 CKT 前後測、實驗組專用意見題及訪談不混入材料，不修改共同測驗。

## A–D 分冊

- **A：自學概念、圖像及示例。** 教導燕麥胚芽鞘保護內部幼葉、正向光性、頂端感光、生長素與向下傳遞、背光側細胞延長較多的彎曲模型；兩側細胞圖共用 VL SVG。示範指定遮光預測、變量辨認及靜態量角器讀法，教導瓊脂承載從頂端取得的生長促進作用。20° 圖只為讀數方法示例，**不是新增實驗資料**；不列出獨立 E–H 答案表。
- **B：有提示練習及獨立應用。** 提供 A/B/C 裝置圖補標示；保留主探究變量、前提、A 比較基準及公平比較理由。以同尺度靜態前後圖記主遮光方向、A/D 有／沒有延長、E–H 的角度及方向。保留三項主分析、切頂結論、三項瓊脂分析（第三項為句內圈選）。獨立辨認不同實驗的變量；觀察原窗邊情境並解釋向右彎曲，連結光源、背光側、生長素與差異延長。沒有「修訂原假說」題。
- **C：核對答案及修正。** 完成 B 並保留首次答案後才派；提供全部觀察及分析核對要點，學生另寫修正與證據。答案不能提早派發。A 一直可供查閱。
- **D：教師指引、完整答案、逐題配對及獨立紙本形成性準則。** 指明研究條件、教師澄清及回饋界限、15/20 分鐘安排、原始答案保留及科學界限；19 項原題／處理／新版／共同目標／理由配對完整收入教師冊，亦自動產生 Markdown。

所有文字作答及修正欄各兩條線；原下拉選項改為句內括號圈選，複選仍使用方格。自主繪圖改為在所提供三組圖補標示，圖像在文字公平比較欄之前。姓名、班別及學號只在 A1、C1（獨立冊及完整套裝一致），不帶入真實個人資料。兩句灰色提醒與 VL 共用及保留原提示：繪圖簡單而標示清楚；假設是未證實而視作正確、確保結果有效的條件。

頁數、套裝頁碼、版本化檔名及全部兩語 PDF／預覽由建置更新至 [materials/README.md](../materials/README.md)、根 README 及 manifest；以這些生成資料為準。

## 科學模型及相容性

| 比較 | 獨立變量 | 共用模型資料／判讀 |
| --- | --- | --- |
| 主遮光 A/B/C | 遮光處理／部位 | 左側光照，頂端完整；A、C 向左彎，B 沒有明顯彎曲 |
| 切頂 A/D | 頂端是否存在 | 同樣左側光照；A 有延長，切頂 D 沒有 |
| 黑暗 E/F | 瓊脂是否曾接觸頂端 | 均放中央；E 不延長，F 延長；兩者角度 0° |
| 黑暗 F/G/H | 處理瓊脂放置位置 | 同種處理瓊脂；中央 F 不彎，左側 G 35° 向右，右側 H 35° 向左 |

主探究三類變量答案只適用於遮光比較，不能套在其他實驗。主比較保持光源方向／強度、種類／初始大小／生長階段、時間、溫度及供水相同。前提包含初始生長狀況相近、遮光物不限制延長或彎曲、不造成明顯溫差。

紙本使用學生標示 **C 下部遮光、D 切頂**，內部 stored D/C 不改，舊答案／快照／Excel 相容邏輯不重編。量角器讀頂端方向偏離鉛直的大小，方向另記；E/F 只接受 0°，G/H 接受 33–37°。瓊脂寬度、位置、隨頂端傾斜、E 不延長與 VL 模型相同。量角器前後圖比例相同，結果圖不預印角度答案。

切頂同時造成傷口及移除組織，不能單靠 A/D 證明唯一機制。瓊脂在黑暗中培養，G/H 彎曲不是當時光照直接造成；反映作用位置與兩側延長的關係。彎曲與延長不是直接量得生長素濃度或鑑定化學身分；生長素的名稱與光照分布結合其他研究理解。24 小時及模型角度不是真實常數；不增加原本沒有量度的長度、速率或濃度數值。

## 教師支援及共同 15–20 分鐘時限

研究者應為兩組統一選定總時間，計入閱讀、作答及回饋。使用者確認兩組均為 **15–20 分鐘**；以下是計劃，尚未以學生試教驗證。

| 階段 | 15 分鐘 | 20 分鐘 | 派發／支援 |
| --- | ---: | ---: | --- |
| A 概念與圖像 | 3 | 4 | 開始即派 A，無課前講授 |
| A 已解說示例 | 2 | 2 | 學生自行閱讀 |
| B1–B4 有提示練習 | 5 | 7 | 派 B，使用紙上共同提示 |
| B5 獨立應用 | 2 | 3 | A 可查閱，不透露個別答案 |
| C 核對修正 | 3 | 4 | B 完成及首次答案保留後才派 C |

A/B 期間教師只澄清程序、字詞及圖表讀法，使用一致的預定提示；不加講授或個別內容答案。需要額外概念教學應記錄為程序偏差。B 完成後才容許以 C 為準提供內容回饋。原答不擦掉；收存原答／副本，修正另記。記錄實際用時及未完成情況，不能僅憑預定分鐘數宣稱兩組實際學習時間已相等。

## 獨立紙本評分

D 提供七項形成性面向，各 0–2，共 **14 分**：靜態觀察及記錄、變量分類、公平比較與前提、證據支持推論、靜態量角讀數、科學表達及另記修正、概念應用。每項含可觀察證據與 0/1/2 判準；量角四組各 0.5，E/F 不接受角度容差。接受科學上等值的文字。

此活動準則不是已驗證量表，不與 VL 32 分、原始預測、虛擬操作、示範或完成分數直接等同。B 首次作答與 C 修正應分開保留；C 有答案可供參考，不能當作獨立成效。研究成效由另外共同的核准測驗評估；原有教師 Excel 完全不改成紙本分數。

## 建置、下載隔離及驗證

`npm run materials:build` 使用隔離 Chromium，從同一來源產生十份真正 A4 PDF 和 HTML 預覽，文字可選、字形嵌入、圖像為向量。新檔名採 `ws2-vl18-{sourceHash}`，與舊 `v18-{hash}` 分開。來源改變會重建全部兩語分冊與套裝，更新 manifest、目錄、配對表及 README，移除舊生成檔。

教師面板先核對 WS2 教學版本及當前來源 digest；下載／預覽再核對 PDF SHA-256。WS2 腳本 URL 使用版本標記；manifest 與 PDF 使用 `cache: no-store`；不接受舊版、錯誤內容或損壞檔。既有教師模式入口保留，不需要雲端學生紀錄解鎖；學生無入口，沒有新增 Apps Script。

生成、預覽及下載不建立探究、不保存答案、圖像、示範、計時、事件或本機／雲端紀錄、不觸及同步佇列、不改教師 Excel。自動測試對比完整狀態、儲存、畫布、控制項、collector 請求及下載前後實際 Excel 位元組；逐一下載兩語十份 PDF，測手機 390px、登出、過期版本及損壞攔截。

PDF 檢查全頁可見文字、嵌入字形、A4 分頁／邊界、實際向量兩條作答線、A1/C1 身份欄位置、兩語溢出及全頁彩色／灰階渲染；另在隔離副本修改來源，驗證重建及清除舊檔。學生 VL、舊紀錄與雲端回歸測試使用隔離服務，正式學生 collector 不接收測試資料。

仍需研究者核對：兩語學生在 15–20 分鐘內閱讀與完成的實際負荷、實體印表機量角器及灰階清晰度、教師澄清一致性、評分者校準、共同測驗及研究程序的正式核准。自動 PDF／瀏覽器測試不是學生試教、實體列印或正式 Google 雲端寫入測試。

實際測試結果見 [PAPER_VALIDATION.md](PAPER_VALIDATION.md)。
