# VL3／WS3：植物的向光生長

版本19；紙本教學版本WS3；rubric `vl19-causal-5`。課題目標是辨識遮光比較的變量與公平比較條件、讀取定性反應和角度、以遮光／切頂／瓊脂比較推論感光與生長作用，並因果解釋右側光照下的向光彎曲。

## 科學模型與限制

VL原編號：主探究左光，A完整不遮光向左、B頂端遮光無明顯彎曲、C下部遮光仍向左。延伸一A有延長，切頂D無延長。內部儲存ID的C／D映射不改。黑暗E空白中央無明顯延長；F處理中央直立延長；G處理左置35°向右；H處理右置35°向左。E/F角度須0°；G/H容差±2°，方向另記。量角讀頂端方向偏離鉛直，不以彎後鉛直高度當延長量。不恢復已刪棒形圖。

頂端參與感光，生長促進作用向下傳遞。生長素是植物激素，不是光或養分；背光側生長素較多，細胞延長較多而向光彎曲。右光時左側背光，左側延長較多向右；左光相反。瓊脂比較支持可轉移作用，不能單獨鑑定物質身分或光下分布。切頂亦涉及傷口和移除組織，不能單靠切頂確定感光機制；D無延長是此模型設定，非植物普遍定律。角度與24小時均為教學模型。
