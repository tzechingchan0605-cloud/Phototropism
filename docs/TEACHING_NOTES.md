# VL3 教學模型、試教及紙本對照

此活動使用燕麥胚芽鞘。介面沿用所提供 VL2 的薄荷綠卡片、四階段探究、固定原始答案、反思鎖定、PDF 及 Excel 評分；延伸安排參考所提供 VL1 的分析後延伸門檻。只修改 Phototropism，未修改 VL1/VL2 原專案。

## 教學順序

學生只需知道植物會朝光源生長。開始只介紹胚芽鞘是保護內部嫩葉的鞘狀構造，外形較直方便觀察。情境的 24 小時為示意；主探究和延伸各採一次加速的「24 小時」培養，未使用 VL2 的 30 分鐘分段模型。

了解情境與初步觀察 → 主探究假說、變量分類、前提、對照及繪圖／相片／文字 → 主探究定性記錄 → 主探究分析 → 瓊脂原始預測與公平比較 → 黑暗培養、角度量度及棒形圖 → 延伸分析 → 確認遞交 → 名稱及機制 → 反思遞交 → PDF。

探究遞交前，顯示的學生情境與分析選項不用「向光性／正向光性」或「生長素」提供答案。不能跳過主探究分析直接運行延伸。可修改錯誤預測，但首次主探究假說、首次延伸預測及理由保留。首次確認觀察、讀數、圖表與最後答案亦保留，另記修訂事件。

試教可暫以 **30–40 分鐘** 為目標：情境 4–5 分鐘、主探究設計 8–10、觀察及分析 7–8、延伸量度／圖表／分析 9–12、學習重點及反思 5 分鐘。這只是規劃，尚未以真實班級驗證。

## 教學模擬假設

- 主探究 A 完整不遮蓋、B 頂端不透光帽、C 切去頂端、D 下部長遮光套。光源在左方；下部保持直立，彎曲由上部逐漸生長形成，不旋轉整株。
- A、B、D 有較明顯伸長；A、D 向左朝光彎曲；B 未明顯彎曲。C 在新版教學模型不伸長而未明顯彎曲；版本 3 的較少伸長設定仍用於其舊紀錄評分。這不代表切頂後必定完全停止生長，實際生長及反應受殘留組織、傷口、植物狀況與條件影響。
- 帽及下部套留有空間並隨生長，不以機械方式夾住胚芽鞘。A–B、A–C、A–D 是三項不同的比較，並非四組同時只改變同一因素。必須控制處理前大小及狀況、種類、光照、溫度、供水與時間。
- 切頂同時移除感光／生長訊號相關組織並造成傷口。因此 C 的結果不能單獨證明頂端只負責感光。遮光結果也依賴沒有明顯溫差及機械限制的假設。
- 延伸 E–H 初始大小相近、均切頂、黑暗培養。E 空白瓊脂中央、F 處理瓊脂中央、G 處理瓊脂左側、H 處理瓊脂右側。E 較少伸長而較直；F 較明顯伸長而較直；G 向右，H 向左。
- 延伸最終方向角 E=0°、F=0°、G=35°向右、H=35°向左，是固定的**教學參數**，不是經典實驗的精確常數或真實數據。量角器從頂端方向與鉛直參考線量度；每次由學生自行調整、分開記角度大小及左右方向。量度的暫定容差為 ±3°。
- 伸長只作定性比較，沒有用彎曲後鉛直高度差計算伸長量。F–G–H 比較的是相同處理瓊脂的位置；E–F 比較的是同中央位置的瓊脂是否曾接觸頂端。
- 瓊脂實驗只支持可轉移的生長促進作用與不均勻生長，未鑑定物質身分，也未直接量得光照下的生長素分布。遞交後才由其他研究介紹生長素機制。可額外用左右放置空白瓊脂排除位置本身影響，不強制增加裝置。

## 紙本對照組同步材料

紙本應保持相同教學順序、情境、題目、模型資料及作答時間。以下資料分階段發放；答案及機制不可印在學生提前可見的頁面。

1. **情境頁**：使用同一窗邊前後圖、「24小時後」教學示意、學校園藝小組情境、主要研究問題，以及初步觀察題。
2. **設計頁**：完全相同的部位選項（請選擇／頂端／頂端以下位置）、預期反應及理由，兩個選單不預選答案；假說句子為「若胚芽鞘＿＿被遮光，而其他部位仍然受光，胚芽鞘將會＿＿。」；A–B／A–C／A–D 比較說明與變量選項（不設指定比較題）；四項假設多選及同樣的假設定義提示、未經處理對照設計題；同樣六類主探究材料及數量（不列培養容器）、自由繪圖或文字空間。固定收存首次預測及理由的副本。
3. **主探究頁**：同一左側光源的 A–D 初始／24小時後靜態圖。填寫伸長表現、向左／向右／無明顯彎曲、彎曲位置，不提前標示答案。首次確認用不同欄位固定保存，後續修訂另記。
4. **主分析頁**：同樣六題選擇及證據文字題，包含切頂傷口及遮光條件限制。未完成前不發延伸結果頁。
5. **延伸預測頁**：同一情境、兩種外觀相同瓊脂的說明、左側處理瓊脂預測／理由、E–F 公平比較題；固定保存首次預測副本。
6. **延伸結果頁**：同一黑暗 E–H 初始及最終靜態圖，用相同角度幾何；提供中性 20° 示例、實體量角器、鉛直參考線，分別填角度及方向。不能直接把 0／35／35° 寫作裝置標籤提示。若研究設計採「提供數據」而非自行量度，VL 組也須同樣處理，避免方法不同。
7. **圖表及延伸分析頁**：空白 E–H 棒形圖座標，Y 軸0–90°、每棒附方向、不連線；同樣五項分析、證據文字及選答的左右空白瓊脂對照。固定首次與最後讀數／圖表。
8. **遞交後材料**：確認遞交收存原答案後，提供同樣四項名稱／機制、原生 SVG 的靜態列印、對照設計參考說明與限制，再發同樣反思題。兩組原始預測及理由供學生引用。
9. **研究紀錄**：保留姓名／班別學號／探究 ID、首次及最後答案、修訂、實際反思，使用同一評分準則及教師人工評分流程。紙本用時或數碼點擊次數均不直接換算能力。

可在本機以教师示範走完流程，列印情境與裝置靜態圖；遞交後 PDF 含答案參考，因此不可當作探究前工作紙整份發放。

## 評分初稿與待確認事項

六項 SPS 各4分共24，新知識四項各2分共8，總32。新版十個人工分數欄：初步觀察2、兩項原始預測2、對照設計1、裝置品質2、證據推論2、反思溝通2，以及四項知識各2。空白是待評，明確0才是零分。其他自動分數見 Excel「評分準則」。

觀察分類、定性結果、主／延伸選擇、角度讀數及圖表自洽性提供自動輔助；開放題、裝置品質及反思由教師評分。圖表以學生自己的讀數核對，量度錯誤不再重複扣圖表分。用時、完成率或點擊不直接評能力。原始預測錯誤不自動扣 SPS。

研究者仍需確認：跨 VL 的難度與權重校準、量角器 ±3° 容差、假說及反思的人工評分錨點、教師間一致性、圖表是否需手繪作公平對照、燕麥材料及培養條件、切頂對照的傷口影響，以及30–40分鐘負荷。本 rubric 是初稿，**未宣稱經效度或信度驗證**。

## 驗證狀態

自動測試用真實前端、真實 Apps Script 程式與模擬 Google 服務，涵蓋完整主／延伸流程、門檻、兩项原始預測、首次與最後讀數、調整量角器、圖表、鎖定、反思、實際PDF／XLSX、切換帳戶、重整確認後空白登入、多次探究、教師完整示範排除、舊資料、離線重試及手機尺寸。Excel實際檔案檢查顏色、圖片、十項人工驗證與24／8／32公式，區分待評和0。尚未在正式 Google 部署、實體手機、桌面 Excel 或真實班級試教驗證。
