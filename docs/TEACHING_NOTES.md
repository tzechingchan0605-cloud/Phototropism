# VL3 教學模型、試教及紙本對照

此活動使用燕麥胚芽鞘。介面沿用所提供 VL2 的薄荷綠卡片、四階段探究、固定原始答案、反思鎖定、PDF 及 Excel 評分；延伸安排參考所提供 VL1 的分析後延伸門檻。只修改 Phototropism，未修改 VL1/VL2 原專案。

## 教學順序

學生只需知道植物會向光源生長。開始只介紹胚芽鞘是保護內部嫩葉的鞘狀構造，外形較直方便觀察。活動名稱保留《幼芽為甚麼向光生長？》，其餘裝置及生物學描述使用「胚芽鞘」。情境的 24 小時為示意；每項探究採一次加速的「24 小時」培養，未使用 VL2 的 30 分鐘分段模型。

了解情境與初步觀察 → 主探究 A／B／D 的遮光假說、公平測試及裝置設計 → 定性觀察與主探究分析 → 延伸一 A／C 的頂端與生長預測、公平比較、觀察及分析 → 提出暫稱「物質 X」的可能解釋 → 延伸二 E／F／G／H 的瓊脂預測、公平比較、黑暗培養、角度量度、棒形圖及分析 → 確認遞交三項探究 → 名稱及機制 → 反思遞交 → PDF。

主探究只改變遮光處理，不包含切頂組。延伸一另比較頂端是否存在及延長反應，再以延伸二探討物質 X 的可能作用。X 是方便檢驗想法的暫稱，並非已被本活動鑑定的物質。

遞交全部探究前，學生情境、題目、選項、提示及參考資料不用「向光性／正向光性」或「生長素」提供答案。只有三項探究的記錄與分析完成並確認遞交後，才介紹名稱及其他研究支持的機制。不能跳過前一項分析直接運行下一項探究。

可修改錯誤預測，但首次主探究假說、首次延伸一預測及首次延伸二預測連同理由各自保留。首次確認的主探究／延伸一定性觀察、延伸二讀數與圖表，以及最後答案亦保留，另記修訂事件。反思須回顧三次原始想法並引用三項探究的比較。

原先 **30–40 分鐘** 是兩項探究流程的規劃，尚未以真實班級驗證。新版加入延伸一後，情境、主探究設計及分析、兩項延伸、學習重點與反思的時間配置須重新試教，不能把原規劃當作已驗證的完成時間。

## 教學模擬假設

- 主探究 A 完整不遮光、B 頂端不透光帽、D 下部長遮光套，三組頂端均保留。光源在左方；A–B、A–D 只比較遮光處理。A、B、D 有較明顯延長；A、D 向左向光彎曲；B 未明顯彎曲。
- 下部保持直立，彎曲由上部逐漸生長形成，不旋轉整株。帽及下部套留有空間並隨生長，不以機械方式夾住胚芽鞘。必須控制處理前大小及狀況、種類、光照、溫度、供水與時間；遮光結果依賴沒有明顯溫差及機械限制的假設。
- 延伸一 A 保留頂端、C 切去頂端；其餘條件相同，另行比較頂端是否存在與延長反應。A 較明顯延長；C 在新版教學模型不延長。切頂也移除其他組織並造成傷口，不能只憑這項比較證明頂端產生某種物質，亦不能確定頂端只負責感光。可提出頂端有生長促進作用或可能有物質 X，再進一步檢驗。
- C 不延長是本模型設定，不代表切頂後必定完全停止生長；實際生長及反應受殘留組織、傷口、植物狀況與條件影響。
- 延伸二 E–H 初始大小相近、均切頂、黑暗培養。E 空白瓊脂中央、F 曾接觸頂端的處理瓊脂中央、G 處理瓊脂左側、H 處理瓊脂右側。E 較少延長而較直；F 較明顯延長而較直；G 向右，H 向左。
- 延伸二最終方向角 E=0°、F=0°、G=35°向右、H=35°向左，是固定的**教學參數**，不是經典實驗的精確常數或真實數據。量角器從頂端方向與鉛直參考線量度；每次由學生自行調整，分開記角度大小及左右方向。G、H 的量度容差為 ±2°，接受 33–37°；E、F 只接受 0°。版本15中，E 的空白瓊脂不提供頂端的生長促進作用，胚芽鞘不延長；F、G、H 的處理瓊脂可促進延長。
- 延長只作定性比較，沒有用彎曲後鉛直高度差計算延長量。F–G–H 比較相同處理瓊脂的位置；E–F 比較同中央位置的瓊脂是否曾接觸頂端。
- 瓊脂實驗支持可轉移的生長促進作用與不均勻生長，可檢驗物質 X 的可能解釋；它沒有直接鑑定 X 的身分或化學性質，也未直接量得光照下的生長素分布。全部探究遞交後，才由其他研究介紹生長素及其機制。可額外用左右放置空白瓊脂排除位置本身影響，不強制增加裝置。

新版紀錄使用 `experimentVersion: 5`。版本 4 與更早的主探究 A–D、舊題目、變量分類、原始回答與評分保留原版本意義，不自動插入延伸一或把舊答案改作新版答案。版本 3 的 C 組較少延長、版本 4 的 C 組不延長，以及更早的透明罩組，按原版本顯示及評閱。

## 紙本對照組同步材料

紙本應保持相同教學順序、情境、題目、模型資料及作答時間。以下資料分階段發放；答案及機制不可印在學生提前可見的頁面。

1. **情境頁**：同一窗邊前後圖、「24小時後」教學示意、學校園藝小組情境、主要研究問題及初步觀察題。
2. **主探究設計頁**：完全相同的部位選項（請選擇／頂端／頂端以下位置）、預期反應及理由，兩個選單不預選答案；假說句子為「若胚芽鞘＿＿被遮光，而其他部位仍然受光，胚芽鞘將會＿＿。」；只列 A–B／A–D 遮光比較及同樣的變量選項、假設多選、假設定義提示、未經處理對照設計題。材料為三株胚芽鞘、頂端不透光帽、下部遮光套、單側光源及計時工具，主探究不列剪刀或培養容器。提供自由繪圖或文字空間，收存首次假說及理由。
3. **主探究觀察頁**：同一左側光源的 A／B／D 初始／24小時後靜態圖。填寫延長、方向及彎曲位置，不提前標示答案。首次確認用不同欄位固定保存，後續修訂另記。
4. **主分析頁**：同樣的主探究選擇及證據文字題，留意遮光比較的溫度及機械限制。未完成前不發延伸一結果頁。
5. **延伸一預測及設計頁**：同一 A 保留頂端／C 切頂情境、延長預測、理由及公平比較題。另列兩株胚芽鞘及剪刀，收存首次預測、理由與公平比較。
6. **延伸一觀察及分析頁**：同一 A／C 初始與培養後靜態圖、定性延長及彎曲觀察、分析與證據文字題；包含切頂傷口及證據限制。只提出暫稱物質 X 的可能解釋，不給出生長素名稱。未完成前不發延伸二結果頁。
7. **延伸二預測頁**：同一物質 X 研究問題、兩種外觀相同瓊脂的說明、左側處理瓊脂預測／理由、E–F 公平比較題；材料為四株切頂胚芽鞘、四個培養容器、一份空白瓊脂、三份處理瓊脂及計時工具；固定保存首次預測副本。
8. **延伸二結果頁**：同一黑暗 E–H 初始及最終靜態圖，使用相同角度幾何；提供中性 20° 示例、實體量角器及鉛直參考線，分別填角度及方向。不能直接把 0／35／35° 寫作裝置標籤提示。若研究設計採「提供數據」而非自行量度，VL 組也須同樣處理。
9. **圖表及延伸二分析頁**：空白 E–H 棒形圖座標，Y 軸0–90°、每棒附方向、不連線；同樣的分析、證據文字及選答的左右空白瓊脂對照。保留首次與最後讀數／圖表，分析以物質 X 的可能作用及證據限制表述。
10. **遞交後材料**：確認三項探究遞交、收存原答案後，提供同樣的名稱／機制、原生 SVG 的靜態列印、對照設計參考說明與限制，再發同樣反思題。三組原始預測及理由供學生引用。
11. **研究紀錄**：保留姓名／班別學號／探究 ID、首次及最後答案、修訂、實際反思，使用同一評分準則及教師人工評分流程。紙本用時或數碼點擊次數均不直接換算能力。

可在本機以教師示範走完流程，列印情境與裝置靜態圖；遞交後 PDF 含答案參考，因此不可當作探究前工作紙整份發放。

## 評分初稿與待確認事項

六項 SPS 各4分共24，新知識四項各2分共8，總32。原始預測評閱須涵蓋三項探究的首次想法與理由；錯誤預測不自動扣 SPS。保留十個人工分數欄，空白是待評，明確0才是零分。其他自動分數見 Excel「評分準則」。

觀察分類、定性結果、主探究／兩項延伸選擇、角度讀數及圖表自洽性提供自動輔助；開放題、裝置品質及反思由教師評分。圖表以學生自己的讀數核對，量度錯誤不再重複扣圖表分。用時、完成率或點擊不直接評能力。舊版紀錄按原版題目及模型評閱。

研究者仍需確認：跨 VL 的難度與權重校準、量角器容差的評分一致性、三項原始預測及反思的人工評分錨點、教師間一致性、圖表是否需手繪作公平對照、燕麥材料及培養條件、切頂對照的傷口影響，以及三項探究的課堂負荷。本 rubric 是初稿，**未宣稱經效度或信度驗證**。

## 驗證狀態

自動驗證使用真實前端、真實 Apps Script 程式與模擬 Google 服務。覆蓋範圍包括三項探究順序與門檻、三項原始預測、主探究及延伸一定性觀察、首次與最後讀數、量角器、圖表、遞交鎖定與延後揭示、反思、實際 PDF／XLSX、語言切換、教師示範排除及舊版本相容。正式 Google 部署、實體手機、桌面 Excel 及真實班級試教仍須分別驗證；自動流程結果不能取代這些驗證。

版本16將延伸二第3題改為句內選項填空：處理瓊脂放左側 → 左側獲得較多物質 X → 左側細胞延長較多 → 向右彎曲。三個答案分別保存及匯出，三個填空各佔該題三分之一，整題權重與其他比較題相同；舊版紀錄保留原選擇題。

版本17刪除延伸二的單側光推論文字題。最後的「學習反思」重現情境中24小時後的窗邊胚芽鞘圖，題目為「試運用學習重點所學，解釋圖中胚芽鞘為何會向右彎曲。」圖與情境頁共用，右側光源、左側背光細胞延長較多的因果解釋由教師評閱。反思區不再展示三段原始預測，但探究紀錄仍保存原始答案；PDF及教師評分準則配合新反思題，舊版紀錄保留原題與已填答案。

版本18將指定題目及提示詞改為紅色，刪除延伸二公平比較說明與填空題標題。F–G–H 比較改用兩個單選項，明確指出經處理瓊脂的放置位置是否影響胚芽鞘的彎曲方向，否定選項的「不」為粗體。G、H 培養完成後，量角器滑桿上方顯示跳動箭嘴，首次調整滑桿後消失；培養前、開始時視圖及提交後不顯示，減少動態效果設定下箭嘴保持靜止。答案值、角度模型及評分權重保持不變，舊版紀錄保留原選項文字。

PDF 的三類變量依現有分類準則自動標示 ✓／✕，並列出實際參考選項。控制變量須完整選對且不多選；未回答不標示對錯，學生原選擇仍保留。此判定與 Excel 分類分數一致。E、F 的角度參考不再顯示容差，PDF 判定與 Excel 分數及顏色均只接受 0°。

Excel「學生探究答案」的獨立變量、因變量及控制變量答案前亦顯示 ✓／✕，正確為綠色，錯誤為紅色；未回答保持空白及原分類顏色。Excel 與 PDF 共用同一判定準則，控制變量漏選或多選都判錯。「教師評分」沿用獨立變量1分、因變量1分、控制變量2分的自動分數；原始選擇保存在完整紀錄快照。

學生及教師列印 PDF 時，預設檔名統一為 `VL3_班別及學號_學生姓名.pdf`，例如 `VL3_X1_Chan Siu Ming.pdf`。中英文介面使用相同格式，姓名中的空格及中文保留，檔名不允許的字元以底線取代。列印預覽開啟期間保留檔名作為文件標題，列印或取消後才恢復頁面標題。
